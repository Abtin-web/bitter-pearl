## 📖 درباره‌ی پروژه

**مروارید تلخ** یک وب‌سایت فروشگاهی (E-commerce) برای فروش قهوه است که با هدف تمرین و تسلط بر طراحی رابط کاربری حرفه‌ای و انیمیشن‌های پیشرفته‌ی وب ساخته شده است. این پروژه بدون استفاده از هیچ فریمورکی، تنها با HTML، CSS و JavaScript خالص توسعه یافته و تلاش کرده حس و حال یک کافه‌ی لوکس را به کاربر منتقل کند.

## ✨ ویژگی‌ها

- 🎨 طراحی مدرن و اختصاصی با تمرکز بر برندینگ قهوه
- 🎬 انیمیشن‌های حرفه‌ای و روان (Scroll Animation، Hover Effects، Transitions)
- 📱 طراحی کاملاً واکنش‌گرا (Responsive) برای موبایل، تبلت و دسکتاپ
- 🛒 نمایش محصولات قهوه با جزئیات و طراحی بصری جذاب
- 🧺 سبد خرید داینامیک با قابلیت افزودن و حذف محصولات به‌صورت لحظه‌ای
- ⚡ عملکرد بهینه و سریع بدون وابستگی به فریمورک‌های سنگین

## 🧺 سبد خرید داینامیک

بخش سبد خرید این پروژه به‌صورت کاملاً داینامیک و با JavaScript خالص پیاده‌سازی شده است:

- ➕ افزودن محصول به سبد خرید با یک کلیک
- ➖ حذف محصول از سبد خرید به‌صورت لحظه‌ای
- 🔄 به‌روزرسانی خودکار تعداد و قیمت کل بدون نیاز به رفرش صفحه
- 💾 مدیریت وضعیت سبد خرید در سمت کلاینت با استفاده از JavaScript

## 🛠️ تکنولوژی‌های استفاده‌شده

| تکنولوژی | کاربرد |
|----------|--------|
| HTML5 | ساختار سمانتیک صفحات |
| CSS3 | استایل‌دهی، Keyframes، Transform و Transition |
| JavaScript (ES6+) | تعامل‌پذیری و منطق داینامیک صفحه |
